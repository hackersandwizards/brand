# Agent Feedback

After a user corrects, refines, or externally edits work you produced, complete the requested
result first, then load `agent-feedback` and improve whatever owns the behaviour, or report the gap
to that artifact's owner where the project names another, before finishing the turn. That skill
owns the counterfactual, the choice of owner, and the action boundary.

Load it before writing or editing a skill, agent definition, rule, hook, permission or MCP server
too: it states what such an artifact leaves out, the history behind a rule included, and the scope
a hook, permission or MCP server goes in.

Load it too when the same failure costs you a second time in one session, without anyone
correcting you.
