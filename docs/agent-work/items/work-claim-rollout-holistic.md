# Claim rollout: tune every surface as a whole before stage 2

The brand run `claim-rollout-brand` was briefed before Benedikt asked for a holistic rollout: it swaps the claim line in the profile texts, reviews the banners as a set only, and writes consumer briefs that paste the claim.

Before any consumer run starts: banners judged in the context of the profiles and the site they sit on; each profile text (LinkedIn About, practitioners bios, Sessionize, OMR) rewritten around the new claim and blind-reviewed in context against the current text; every consumer brief carrying the rule that a surface's copy around the claim or the headline is rewritten to fit and reviewed in that surface's context, aiming at the highest score.
