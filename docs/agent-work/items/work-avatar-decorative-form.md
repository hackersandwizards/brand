# The avatar documents a decorative form for a mark whose name stands beside it

A brand session documents, and where needed adds, how `hw-avatar` is drawn when the person's name
already stands next to it, so a screen reader does not read the name twice.

The website moved its person marks to `hw-avatar`. Its training page shows trainer faces without a
name beside them in one place and with one in another; the site could not move those faces because
the avatar names no decorative form. Done when the avatar's documentation states the form, the
catalog shows it, and a test checks it.
